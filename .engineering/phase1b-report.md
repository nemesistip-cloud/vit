### Root cause of local build friction

The Replit environment's pnpm version (`9.x` in Dockerfile, latest locally) was incompatible with the `pnpm-lock.yaml` format, causing pnpm to move `@types/react`, `@types/react-dom`, and other packages from `frontend/node_modules` to `frontend/node_modules/.ignored`. This broke TypeScript's JSX type resolution.

**Fix (local only):** Re-ran `npm install --legacy-peer-deps` inside `frontend/` to restore the packages, then symlinked `frontend/node_modules/vite → repo/node_modules/vite` so `@vitejs/plugin-react` (resolved from the workspace root) could find Vite at runtime. These are Replit-environment-only workarounds; the Render Dockerfile uses `pnpm@9 install --frozen-lockfile` which works correctly in the Docker layer cache.
