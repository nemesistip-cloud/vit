# ADR-003: ADR System Mandatory

- **Date**: 2025-06-30
- **Status**: Accepted
- **Context**: Major architectural decisions were previously documented in a single file or lost in chat history.
- **Decision**: Make the Architecture Decision Record (ADR) system mandatory for all major changes. Use `.engineering/adr/` directory for storage.
- **Consequences**:
  - Historical record of architectural evolution.
  - Transparent decision-making process.
  - Standardized format for proposals.
