# 15 Documentation Standards

## 1. Code Documentation
- Use Python docstrings for all modules, classes, and functions.
- Use JSDoc for complex React components and hooks.

## 2. Project Documentation
- The `README.md` is the entry point for humans.
- The `.engineering/` directory is the authoritative source for architectural rules.
- Keep documentation in sync with code.

## 3. ADR (Architectural Decision Records)
- Major architectural changes must be recorded in `18_DECISION_RECORDS.md`.
