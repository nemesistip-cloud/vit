Wallet Overview
Method
Path
Notes
GET
/api/wallet
Return wallet balances: vitcoin_balance, ngn_balance, usd_balance, usdt_balance. Include staked amount, pending withdrawals total, and 30d earnings.
GET
/api/wallet/transactions
Paginated transaction history. Params: page, limit, type, currency, status, date_from, date_to. Return: id, type, amount, currency, direction, status, reference, created_at, description.
GET
/api/wallet/transactions/{tx_id}
Single transaction detail.
Deposits
Method
Path
Notes
POST
/api/wallet/deposit/initiate
Fields: amount, currency (NGN or USD). For NGN: create Paystack payment link via Paystack API. For USD: create Stripe PaymentIntent. Return: payment_url or client_secret. Write WalletTransaction with status pending.
GET
/api/wallet/deposit/verify/{reference}
Manually verify a Paystack payment by reference. Update transaction status. Credit wallet on success.
Withdrawals
Method
Path
Notes
POST
/api/wallet/withdraw
Fields: amount, currency, bank_code, account_number, account_name. Validate: sufficient balance, daily limit from PlatformConfig withdrawal_limits, KYC status if amount > threshold. Debit wallet immediately, create WalletTransaction status pending_review. Queue Celery task.
GET
/api/wallet/withdraw/status/{tx_id}
Return withdrawal status and any rejection reason.
VITCoin
Method
Path
Notes
GET
/api/wallet/vitcoin/price
Current price from latest VITCoinPriceHistory row. Include 24h change %, 7d price array, circulating supply, market cap.
GET
/api/wallet/vitcoin/price/history
Params: days (default 30, max 365). Return OHLCV array from VITCoinPriceHistory.
POST
/api/wallet/vitcoin/buy
Fields: amount_ngn or amount_usd. Calculate VITCoin received at current price + conversion fee from PlatformConfig. Debit fiat, credit VITCoin. Write both transactions. Idempotency key via request header X-Idempotency-Key.
POST
/api/wallet/vitcoin/sell
Fields: vitcoin_amount. Calculate fiat received. Debit VITCoin, credit fiat. Write both transactions. Idempotency key required.
Staking
Method
Path
Notes
POST
/api/wallet/stake
Fields: amount. Minimum from PlatformConfig vitcoin_min_stake. Debit vitcoin_balance, credit staked_balance. Write transaction type stake.
POST
/api/wallet/unstake
Fields: amount. Validate: amount ≤ staked balance. Credit back to vitcoin_balance. Write transaction type unstake.
GET
/api/wallet/stake/status
Return: staked amount, unlock date if any, estimated rewards accrued.
Currency Conversion
Method
Path
Notes
POST
/api/wallet/convert
Fields: from_currency, to_currency, amount. Use rates from PlatformConfig exchange_rates_usd. Apply fee from conversion_fee_pct. Validate sufficient balance. Write two transactions (debit + credit). Idempotency key required.
GET
/api/wallet/convert/quote
Params: from_currency, to_currency, amount. Return: received_amount, fee, rate, rate_expires_at (30 seconds). No state change.

Notes
