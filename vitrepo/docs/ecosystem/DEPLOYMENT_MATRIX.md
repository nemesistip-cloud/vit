## 2. Infrastructure Requirements

- **Database**: PostgreSQL 15+ (Production: Render Postgres / Cloud SQL).
- **Cache**: Redis 7+ (Production: Render Redis).
- **Storage**:
  - Tachyon: Multiprovider (GDrive, Dropbox, Local).
  - AI Models: Google Cloud Storage.
- **Secrets**:
  - Render Secret Manager.
  - Google Cloud Secret Manager.

## 3. Environment Variables (Critical)
- `JWT_SECRET_KEY`: For authentication.
- `DATABASE_URL`: Primary persistence.
- `REDIS_URL`: Task queue and cache.
- `ENVIRONMENT`: Set to `production`.
- `GCP_PROJECT_ID`: For cloud services integration.
