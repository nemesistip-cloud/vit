# VIT Service Catalog

## 1. Classification Methodology
Every repository/module in the VIT ecosystem is classified into one of the nine authoritative categories to ensure clear operational boundaries.

## 2. Catalog

### 2.1 Core Runtime Services
*High-availability services that form the backbone of the VIT network.*
- **vit (Core Platform)**: The central FastAPI application gateway.
- **vit-network**: The blockchain node and P2P communication layer.
- **vit-storage (Tachyon)**: The distributed storage coordination service.

### 2.2 Supporting Runtime Services
*Auxiliary services that enhance the core platform.*
- **vit-ai**: The model inference and training engine.
- **vit-agents**: Autonomous agent coordination environment.
- **vit-node (Daemon)**: Background validator processes.

### 2.3 Static Sites
*Client-side applications served via CDN.*
- **vit-explorer**: The blockchain and storage dashboard.
- **vit-docs**: Technical documentation and whitepapers.

### 2.4 SDK / Libraries
*Tools for developers to interact with the VIT ecosystem.*
- **vit-sdk (Python)**: Official Python integration library.
- **vit-sdk (JS/TS)**: Web-based integration library (in `packages/sdk`).

### 2.5 Mobile Applications
*End-user mobile interfaces.*
- **vit-mobile**: Flutter/Expo-based super-app (mapped to `app/modules/network/mobile_relay.py` for infra).

### 2.6 Infrastructure
*Provisioning and orchestration logic.*
- **vit-devops**: Terraform, CloudBuild, and Render configurations.

### 2.7 Documentation
*Authoritative engineering and product guides.*
- **.engineering**: VIT Engineering Constitution and ADRs.
- **docs**: General project documentation.

### 2.8 Blockchain Components
*On-chain logic and consensus definitions.*
- **vit-contracts**: Solidity smart contracts.
- **vit-chain (Consensus)**: Consensus engine and block production logic.

### 2.9 Deployment Automation
*CI/CD pipelines and scripts.*
- **.github**: GitHub Actions workflows.
- **scripts**: Utility and deployment scripts.
