## PHASE 2 — REBUILD

### Step 1: Create the `require_admin` dependency

File: `app/api/dependencies/admin.py`

```python
from app.auth.jwt_utils import get_current_user
from app.core.errors import AppError
from app.db.models import User
from fastapi import Depends

async def require_admin(current_user: User = Depends(get_current_user)) -> User:
    if current_user.role != "admin":
        raise AppError(status_code=403, code="forbidden", message="Admin access required")
    return current_user

async def require_super_admin(current_user: User = Depends(require_admin)) -> User:
    if current_user.admin_role != "super_admin":
        raise AppError(status_code=403, code="forbidden", message="Super admin access required")
    return current_user
```

### Step 2: Create the audit log model and helper

**If `AuditLog` does not exist in `app/db/models.py`**, append this class (do not modify any existing class):

```python
class AuditLog(Base):
    __tablename__ = "audit_logs"
    id = Column(Integer, primary_key=True)
    admin_id = Column(Integer, ForeignKey("users.id"), nullable=False)
    action = Column(String(100), nullable=False)
    target_type = Column(String(50))

```

File: `app/services/audit.py`

```python
from app.db.models import AuditLog
from sqlalchemy.ext.asyncio import AsyncSession

async def write_audit(
    db: AsyncSession,
    admin_id: int,
    action: str,
    target_type: str = None,
    target_id=None,
    before: dict = None,
    after: dict = None,
    request=None,
):
    ip = request.client.host if request and request.client else None
    db.add(AuditLog(
        admin_id=admin_id,
        action=action,
        target_type=target_type,
        target_id=str(target_id) if target_id is not None else None,
        before_state=before,
        after_state=after,
        ip_address=ip,
    ))
    await db.commit()
```

Call `await write_audit(...)` in every route that mutates state.
