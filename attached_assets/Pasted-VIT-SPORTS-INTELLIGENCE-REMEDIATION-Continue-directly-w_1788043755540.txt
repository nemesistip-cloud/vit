5. DATA PROVENANCE

Every prediction should be traceable.

Where appropriate, return metadata similar to:

{
  "data_source": "football-data.org",
  "source_type": "live",
  "retrieved_at": "2026-08-29T...",
  "fallback_used": false
}

Use the actual provider and actual retrieval timestamp.

Support states such as:

- "LIVE"
- "CACHED"
- "DEGRADED"
- "UNAVAILABLE"

Never silently convert "UNAVAILABLE" into fake data.

Training datasets may be used by models where appropriate, but training fixtures must never masquerade as current match data.
