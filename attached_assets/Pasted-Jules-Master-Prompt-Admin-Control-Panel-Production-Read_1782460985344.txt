CONTEXT: TECH STACK
Backend: FastAPI + async SQLAlchemy + Python 3.11. Database session via AsyncSessionLocal. Config via get_env() / get_int_env() helpers in app/config.py.
Frontend: React 19, Zustand state, Tailwind CSS utility classes only (no custom CSS files unless strictly necessary). Dark theme. Accent colors: #00E676 (green), #8B5CF6 (purple). Fonts: Barlow Condensed, Outfit, JetBrains Mono. Aesthetic: "control room / trading terminal".
Auth: JWT bearer tokens. Admin role check: current_user.role == "admin". Admin sub-roles: "super_admin", "support", "analyst". Use the existing get_current_user dependency from app/auth/jwt_utils.py.
Database: Neon PostgreSQL in production, SQLite in development. All queries must be async (await db.execute(...)).
Cache: Redis mandatory in production. Use app/core/redis.py helpers for cache reads/writes. Cache key namespace: admin:.
Models: All SQLAlchemy models imported via app/db/models.py and module-level models.py files. Never redefine a model — import it.
Background tasks: Celery + Redis. Do not create new asyncio.create_task calls inside route handlers.
Error handling: Use AppError from app/core/errors.py for all raised exceptions. Use error_response() for handler returns.
Payments: Paystack and Stripe webhooks already built. Do not touch webhook files.

User Management (app/api/routes/admin.py)
GET /api/admin/users — paginated user list. Params: page, limit, search (username/email), role, subscription_tier, is_active. Returns: id, email, username, role, subscription_tier, is_active, created_at, wallet balance, total_predictions, last_login.
GET /api/admin/users/{user_id} — full user detail including wallet, predictions count, CLV score, validator status, referral count.
PATCH /api/admin/users/{user_id} — update role, subscription_tier, is_active, withdrawals_frozen, is_flagged. Write audit log entry on every change.
POST /api/admin/users/{user_id}/reset-password — force password reset email. Log action.
DELETE /api/admin/users/{user_id} — soft delete (set is_active=False). Require super_admin sub-role.
GET /api/admin/users/export — CSV export of user list with filters.
Wallet & Finance (app/modules/wallet/admin_routes.py)
GET /api/admin/wallet/transactions — paginated transaction list. Params: user_id, type, status, currency, date_from, date_to.
POST /api/admin/wallet/manual-credit — credit VITCoin or NGN to a user wallet. Required fields: user_id, amount, currency, reason. Write WalletTransaction with type admin_credit. Write audit log.
POST /api/admin/wallet/manual-debit — same as above but debit. Validate sufficient balance. Write audit log.
GET /api/admin/wallet/vitcoin-price — current price, price history (last 30 days OHLCV), circulating supply.
POST /api/admin/wallet/vitcoin-price/override — manually set VITCoin price. Require super_admin. Write to VITCoinPriceHistory. Write audit log.
GET /api/admin/wallet/platform-revenue — total platform revenue by currency, fee revenue, 30d trend.
GET /api/admin/wallet/withdrawal-queue — pending withdrawals sorted by created_at. Include user KYC status.
POST /api/admin/wallet/withdrawal/{tx_id}/approve — approve withdrawal. Write audit log.
POST /api/admin/wallet/withdrawal/{tx_id}/reject — reject with reason. Write audit log.
Match & Prediction Management (app/api/routes/admin.py)
GET /api/admin/matches — paginated match list. Params: status, league, sport, date_from, date_to.
PATCH /api/admin/matches/{match_id}/result — set actual_outcome, home_goals, away_goals. Trigger settlement job via Celery task tasks.settle_match. Write audit log.
DELETE /api/admin/matches/{match_id} — soft delete match and cascade-void its predictions. Write audit log.
GET /api/admin/predictions — paginated prediction list with user, match, CLV data. Params: user_id, match_id, was_correct, date_from, date_to.
POST /api/admin/predictions/recalculate-clv — queue Celery task to recalculate CLV for all settled predictions. Return job_id.

GET /api/admin/validators/appeals — list pending validator appeals.
