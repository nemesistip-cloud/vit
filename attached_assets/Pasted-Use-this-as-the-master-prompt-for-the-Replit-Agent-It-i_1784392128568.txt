VIT Network Engineering Program

## Phase 1: Platform Core

You are working on the VIT Network ecosystem.

Your mission is to implement ONLY the current phase of the roadmap. Do not skip ahead to future phases unless they are required to complete the current objective.

--------------------------------------------------
CURRENT PHASE
--------------------------------------------------

Phase 1: Platform Core

Build and complete the shared platform services that every VIT product depends on.

Deliverables

### Identity

Implement and verify:

- Unified authentication
- Organisations
- Teams
- Roles & Permissions
- Sessions
- Devices
- API Keys

### Event Bus

Create a central event-driven architecture.

Required events include:

- User Registered
- Wallet Created
- Storage Initialized
- AI Profile Created
- Analytics Updated

Every service should communicate through events instead of tightly coupled calls where appropriate.

### Notification Centre

Build one notification service supporting:

- In-app notifications
- Email notifications
- Push notification foundation
- SMS interface placeholder

### Global Search

Implement unified search capable of indexing:

- Users
- Files
- Wallets
- AI resources
- Predictions
- Marketplace items
- Transactions

### Global AI Assistant

Build the platform-wide assistant so it can be accessed throughout the VIT ecosystem.

The assistant should be architected to support multiple AI providers in the future.

### Command Palette

Implement a registry-driven command palette capable of:

- Global navigation
- Opening applications
- Executing workspace actions
- Searching commands
- Launching registered apps

--------------------------------------------------
ENGINEERING WORKFLOW
--------------------------------------------------

For every deliverable, execute this workflow exactly.

1. Discover the current implementation.
2. Audit the existing code.
3. Identify completed work.
4. Identify missing functionality.
5. Produce a concise implementation plan.
6. Implement only the approved scope.
7. Test locally.
8. Build the frontend and backend.
9. Verify all automated tests pass.
10. Deploy to Render.
11. Monitor deployment health.
12. Verify production manually.
13. Exercise the production application:
    - Register
    - Login
    - Dashboard
    - Workspace
    - Wallet
    - Notifications
    - Search
    - Command Palette
14. Check browser console for errors.
15. Check browser network requests.
16. Fix any discovered issues.
17. Commit changes.
18. Push to GitHub.
19. Produce an engineering report.
20. Stop.

Do not continue into another feature automatically.
