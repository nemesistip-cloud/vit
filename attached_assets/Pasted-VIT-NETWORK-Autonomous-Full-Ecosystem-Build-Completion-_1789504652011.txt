37. PRODUCT LOGIC RULE

When the code is incomplete but the intended behavior is clear from the architecture, implement the missing business logic.

For example:

If VIT is designed to provide evidence-based sports intelligence, the system should not generate a confident prediction from nonexistent data.

If VIT displays wallet balances representing real funds, the balance must be derived from authoritative accounting.

If VIT claims blockchain transactions, the system must actually reconcile blockchain state.

If VIT claims AI intelligence, AI outputs must enter a controlled intelligence pipeline.

The objective is functional truth, not visual completeness.
