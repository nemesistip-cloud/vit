# VIT Blockchain: Africa's Largest Digital Super Network

## Vision
VIT is transforming from a sports intelligence platform into a comprehensive **AI Intelligence Oracle and Blockchain Super App**. We are modernizing the African digital economy, starting with Nigeria, by providing verifiable insights and seamless financial services across multiple sectors.

## Core Pillars
- **AI Intelligence Oracle**: High-confidence signals for sports, elections, commodities, and policy.
- **Modern Betting Shops**: Empowering shop owners as VIT Agents with on-chain settlement and commissions.
- **Universal Marketplace**: A unified hub for intelligence, e-commerce, and community collaboration.
- **Massive Financial Inclusion**: Gasless transactions (Passkeys), mobile money integration, and cross-border remittances.

## Repository Structure
- `app/`: FastAPI Backend (AI engines, prediction logic).
- `frontend/`: React 19 Super App (Mobile-first, Tabbed Dashboard).
- `packages/contracts/`: Core Smart Contracts (Foundry, Base L2).
- `packages/sdk/`: TypeScript SDK for ecosystem developers.

## Scale Target
- **Year 1**: 10 Million Users in Nigeria.
- **Year 3**: 100 Million Users across Africa.
